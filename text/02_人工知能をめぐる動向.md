# 02 人工知能をめぐる動向

> 01章の「3度のAIブーム」年表の、各時代の**技術の中身**を見る章。第1次＝探索・推論、第2次＝知識表現、第3次＝機械学習・ディープラーニング。システム名と開発者・年号・分野の組み合わせがよく問われる。

## この章で押さえること

- **探索**（第1次）: 幅優先探索と深さ優先探索の長所・短所、ハノイの塔の最小手数 **2ⁿ−1**、ゲームの探索（**ミニマックス法 → αβ法 → モンテカルロ法**）。
- **知識表現**（第2次）: エキスパートシステム（**DENDRAL**＝化学、**MYCIN**＝医療）、**意味ネットワーク**（is-a と part-of）、**オントロジー**（ヘビーウェイトとライトウェイト）、**Cyc**、**ワトソン**。
- **機械学習の台頭**（第3次）: ルールを書く方式から**データで学ぶ方式**へ（ルールベース機械翻訳 → 統計的機械翻訳）。ビッグデータ、ただし特徴量の設計と**次元の呪い**が壁になった。
- **ディープラーニングの台頭**: **ネオコグニトロン（1980、福島邦彦）→ LeNet（ルカン）→ AlexNet（2012、ILSVRC）**。

## 2-1 探索・推論（第1次AIブーム）

### 探索木
- **一言で**: 問題の状態を**ノード**、状態を変える操作を**枝**として、スタートから枝分かれしていく木の形に表したもの。迷路なら、分かれ道がノード、進む方向が枝。
- **なぜ**: 「問題を解く」ことを「スタートの状態からゴールの状態までの道を探す」ことに置き換えれば、コンピュータで機械的に解ける。これが第1次ブームの基本的な考え方。
- 木のたどり方で、次の2つに分かれる。

### 幅優先探索と深さ優先探索

| | 幅優先探索 | 深さ優先探索 |
|---|---|---|
| たどり方 | スタートに**近いノードから順に**、同じ深さを全部調べてから次の深さへ | 行けるところまで**奥へ進み**、行き止まりなら1つ戻って別の枝へ |
| 最短経路 | **必ず見つかる**（最初に見つけたゴールが最短） | **保証されない** |
| メモリ | **多く使う**（調べ途中のノードを全部覚える） | **少なくて済む**（今たどっている道だけ覚える） |
| 苦手なこと | 木が広いとメモリが足りなくなる | 木が深い（無限に続く）と戻ってこられないことがある |

- **問われ方**: 「最短経路が保証されるがメモリを多く使う」→ 幅優先。「メモリは少ないが最短の保証がない」→ 深さ優先。

### ハノイの塔
- **一言で**: 3本の棒と大きさの違う円盤を使うパズル。すべての円盤を別の棒に移す。1883年にフランスの数学者リュカが発表した。
- **ルール**: ①1回に1枚しか動かせない ②小さい円盤の上に大きい円盤を置けない。
- **最小手数**: 円盤 n 枚なら **2ⁿ − 1 回**（3枚で7回、4枚で15回、10枚で1,023回）。
  - 理由: n枚を移すには「上の n−1 枚をよける → 一番下を動かす → n−1 枚を戻す」が必要で、手数が毎回「2倍＋1」になる。
- **位置づけ**: 探索で解けるトイプロブレムの代表例。

### ブルートフォース（総当たり）
- **一言で**: 考えられる組み合わせを**すべて**試す方法。必ず答えが見つかるが、組み合わせが増えると計算量が爆発する（**組み合わせ爆発**）。
- **ゲームでの規模感**（探索する局面の数の目安）:

| ゲーム | 局面（探索空間）の数の目安 |
|---|---|
| オセロ | 約10の60乗 |
| チェス | 約10の120乗 |
| 将棋 | 約10の220乗 |
| 囲碁 | 約10の360乗 |

- 宇宙の原子の数（約10の80乗）よりはるかに多いので、チェス以上のゲームでは総当たりは不可能。そこで、探索を**減らす工夫**（αβ法）や**サンプリング**（モンテカルロ法）が生まれた。
- **補足**: セキュリティでは、パスワードを総当たりで試す攻撃（ブルートフォース攻撃）として出てくる（→ 10章）。

### プランニングと STRIPS
- **プランニング**: ロボットなどが目標を達成するための**行動の順番（計画）**を、探索で自動的に作ること。
- **STRIPS**: 1971年に米国スタンフォード研究所（SRI）のファイクスとニルソンが開発した自動計画のシステム。各行動を次の3つで記述する。

| 要素 | 意味 | 例:「ドアを開ける」 |
|---|---|---|
| 前提条件 | その行動ができる条件 | ドアの前にいる、ドアが閉まっている |
| 行動 | 何をするか | ドアを開ける |
| 結果 | 行動後に状態がどう変わるか | ドアが開いている |

- 移動ロボット **Shakey（シェーキー）** の行動計画に使われた。

### SHRDLU（シュルドゥル）
- **一言で**: 1970年前後に **テリー・ウィノグラード**（MIT）が開発した、英語で指示すると画面の中の「**積み木の世界**」を操作するシステム。
- **できたこと**: 「赤いブロックを青い箱に入れて」のような指示を理解して実行し、「なぜそうしたか」の質問にも答えられた。
- **限界**: 積み木の世界の中だけで動き、現実世界には広げられなかった（**トイプロブレム**の代表例）。
- **その後**: ウィノグラード自身は、後に記号処理によるAIの限界を論じる立場に移った。

ゲームの探索は **ミニマックス法 → αβ法 → モンテカルロ法** の順に発展した。

### ミニマックス法
- **一言で**: 「自分は自分の得点が**最大**になる手を、相手は自分の得点が**最小**になる手を選ぶ」と仮定して先読みし、最善手を選ぶ方法。
- **仕組み**: 数手先の局面のスコア（評価関数で計算）を、下から順に「相手の番なら最小を、自分の番なら最大を」選んで上に伝えていく。
- **弱点**: 読む手数を深くすると、調べる局面が爆発的に増える。

### αβ法
- **一言で**: ミニマックス法で、**結果に影響しないと分かった枝の探索を打ち切る（枝刈り）**ことで効率化した方法。答え（選ばれる手）はミニマックス法と同じで、計算量だけが減る。
- **2種類の打ち切り**:

| | どこで起きるか | 内容 |
|---|---|---|
| **αカット** | 自分の番（最大を選ぶ）の下で | すでに得た最大値より**小さく**なることが確定した枝を打ち切る |
| **βカット** | 相手の番（最小を選ぶ）の下で | すでに得た最小値より**大きく**なることが確定した枝を打ち切る |

- **例**: 自分の手Aを調べたら、相手がどう応じてもスコアは5以上だった。次に手Bを調べ始めたら、相手のある応手でスコアが3になった。手Bは「相手が最小を選ぶ」ので最大でも3にしかならず、Aの5より悪いことが確定する。そこで手Bの残りの応手は調べない（αカット）。
- **問われ方**: 「αβ法はミニマックス法の何を改良したか」→ 探索する局面の数を減らした（結果は同じ）。αカットとβカットの入れ替えにも注意。

### モンテカルロ法
- **一言で**: **乱数を使った試行を大量に繰り返し**、その結果から近似的な答えを出す方法の総称。例: 正方形の中にランダムに点を打ち、内接する円に入った割合から円周率を求める。
- **ゲームでの使い方**: ある局面から、双方が**ランダムに最後まで打つ（プレイアウト）**のを何千回も繰り返し、**勝率が高い手**を選ぶ。
- **なぜ画期的か**: ミニマックス法・αβ法は、局面の良し悪しを数値にする**評価関数**を人が作る必要がある。囲碁は良い評価関数を作るのが極めて難しかったが、モンテカルロ法なら評価関数なしで、「終局させて勝ち負けを数える」だけで局面を評価できる。
- **発展**: 有望な手ほど多く試行するように木を育てる**モンテカルロ木探索（MCTS）**が2006年ごろに登場し、囲碁AIが急に強くなった。AlphaGo もこれにディープラーニングを組み合わせた（→ 2-4、06章）。

### ゲームAIの年表（探索がどこまで来たか）

| 年 | 出来事 |
|---|---|
| 1997 | IBMの **Deep Blue** がチェスの世界王者 **ガルリ・カスパロフ** に勝つ（6局で2勝1敗3分）。専用ハードウェアによる大規模な探索 |
| 1997 | オセロの **Logistello** が世界王者の村上健に6戦全勝 |
| 2006 | 将棋の **Bonanza**（保木邦仁）が世界コンピュータ将棋選手権で優勝。評価関数を**プロの棋譜から機械学習**する手法を広めた |
| 2013 | 第2回電王戦で、**現役**の将棋のプロ棋士が公開の対局で初めてコンピュータに敗れる |
| 2016 | **AlphaGo**（DeepMind）が囲碁のトップ棋士 **イ・セドル** に4勝1敗 |
| 2017 | 将棋の **Ponanza** が現役名人（佐藤天彦）に2連勝。囲碁では AlphaGo が世界ランク1位の柯潔に3連勝 |

- **流れ**: 「探索の力ずく（Deep Blue）」→「評価関数の機械学習（Bonanza）」→「モンテカルロ木探索＋ディープラーニング＋強化学習（AlphaGo）」。

## 2-2 知識表現とエキスパートシステム（第2次AIブーム）

### エキスパートシステム
- **一言で**: ある分野の専門家の知識を「もし〜ならば〜」の**ルール**として大量に入れ、専門家のように推論して答えを出すシステム。
- **構成**: 知識を蓄える**知識ベース**と、ルールを使って結論を導く**推論エンジン**に分かれる。
- **推論の向き**:
  - 前向き推論: 分かっている事実からルールを順に当てはめ、結論を導く。
  - 後ろ向き推論: 結論（仮説）を立て、それを支える事実があるかを逆向きに確かめる。MYCIN はこちら。
- **代表例**:

| システム | 開発 | 分野 | ポイント |
|---|---|---|---|
| **DENDRAL** | 1965年〜、スタンフォード大学（ファイゲンバウム、レーダーバーグら） | **化学**: 質量分析のデータから未知の有機化合物の構造を推定 | **最初のエキスパートシステム**とされる |
| **MYCIN** | 1970年代前半〜、スタンフォード大学（ショートリッフ） | **医療**: 血液の細菌感染症の診断と、抗生物質の提案 | 約500のルール。確信度（どのくらい確からしいか）を扱った。専門医には及ばないが、専門外の医師より良い成績を示した |

- **限界**: 知識獲得のボトルネック（01章）。さらに、ルールの外にある状況には対応できず、常識を持たないので、明らかにおかしい入力にも機械的に答えてしまう。
- **問われ方**: 「DENDRAL＝化学、世界初」「MYCIN＝医療（感染症）」の取り違え。

### インタビューシステム
- **一言で**: 専門家に**質問を重ねて**、暗黙的な知識を引き出し、ルールとして整理するための仕組み・手法。
- **なぜ**: 専門家は自分の知識を体系的に説明できないことが多い。質問形式なら引き出しやすい。知識獲得のボトルネックを和らげる工夫の1つ。

### 意味ネットワーク
- **一言で**: 概念を**ノード**、概念どうしの関係を**矢印（ラベル付きの辺）**で表した知識の表し方。1960年代にクィリアンが提案した。
- **主な関係**:

| 関係 | 意味 | 例 | 性質 |
|---|---|---|---|
| **is-a** | 「AはBの一種である」（上位・下位） | 猫 is-a 哺乳類、哺乳類 is-a 動物 | **推移律が成り立つ**（猫は動物）。上位の性質を下位が**継承**する |
| **part-of** | 「AはBの一部である」（部分・全体） | 目 part-of 頭 | 部分・全体の関係にはいくつか種類があり、**推移律が成り立たない場合がある** |
| **has-a** | 「AはBを持つ」 | 頭 has-a 目 | part-of を逆向きに見た関係 |

- **問われ方**: 関係の種類の識別。「is-a は継承関係で推移律が成り立つ」。
- **part-of の推移律が崩れる例**: 「ドアノブはドアの一部」「ドアは家の一部」から「ドアノブは家の一部」は言えそうだが、「田中さんの手は田中さんの一部」「田中さんは営業部の一部（メンバー）」から「田中さんの手は営業部の一部」とは言わない。このように部分・全体の関係は単純ではない。

### オントロジー
- **一言で**: 概念と概念の関係を、**コンピュータが扱えるように明確に定義したもの**。もとは哲学の「存在論」の用語。AIでは「概念化の明示的な仕様」（グルーバーの定義）として使われる。
- **なぜ必要か**: 知識ベースを大きくするほど、人によって言葉の使い方がずれ、知識の共有・再利用ができなくなる。言葉の意味と関係を厳密に決めておく必要があった。
- **2つの立場**:

| | ヘビーウェイトオントロジー | ライトウェイトオントロジー |
|---|---|---|
| 作り方 | 人が時間をかけて、**厳密に**概念と関係を定義する | データから**自動で**関係を見つける。完全な正しさにはこだわらない |
| 長所 | 正確 | 大量に作れる |
| 短所 | 作るのに膨大な手間がかかる。哲学的な議論が必要 | 正しくない関係が混じる |
| 例 | Cyc | ウェブマイニングやデータマイニングで作る知識、ワトソン |

- **問われ方**: 両者の特徴の入れ替え。「データから自動で作る＝ライトウェイト」。

### Cyc（サイク）プロジェクト
- **一言で**: **人間の一般常識をすべて**コンピュータに入力しようとするプロジェクト。**1984年**に **ダグラス・レナート** が始めた。
- **入力する知識の例**: 「人は死ぬ」「水は高い所から低い所へ流れる」「物は支えがないと落ちる」。
- **現状**: 1994年からは企業（Cycorp）が引き継ぎ、40年近く知識を入力し続けたが完成していない。レナートは2023年に亡くなった。
- **意味**: 常識がいかに膨大で、手で書き尽くすのがいかに難しいか（知識獲得のボトルネック）を示す代表例。ヘビーウェイトオントロジーの代表でもある。

### セマンティックWeb
- **一言で**: Webページに「これは人名」「これは日付」といった**意味の情報（メタデータ）**を付け、コンピュータが内容の意味を理解して処理できるようにする構想。
- **人物**: Webの考案者 **ティム・バーナーズ＝リー** が提唱した（2001年の論文で広く知られた）。
- **関係**: オントロジーを Web 全体に適用する試み。現在は、検索エンジンが使う構造化データ（ナレッジグラフ）などに形を変えて生きている。

### 質問応答とワトソン
- **質問応答（クエスチョンアンサリング）**: 自然な言葉の質問に対して、**答えそのもの**を返す研究分野。検索エンジンが関連する文書の一覧を返すのとは違う。
- **ワトソン（Watson）**: **IBM** が開発した質問応答システム。**2011年**、米国のクイズ番組 **「ジェパディ!」** で、歴代のチャンピオン2人に勝った。
  - **仕組み**: Wikipedia などの大量の文書から答えの候補を多数集め、それぞれの確からしさを多くの観点で評価して答えを選ぶ。**ライトウェイトオントロジー**の代表例とされる。
  - **ポイント**: 質問の**意味を理解して**答えているのではなく、質問に含まれる語句と関連の強い答えを統計的に選んでいる。
  - **その後**: 医療（Watson Health）などに応用されたが、医療事業は期待どおりの成果を出せず、2022年に売却された。現在、IBMのAI事業は watsonx というブランドで展開されている。

### 東ロボくん
- **一言で**: 「ロボットは東大に入れるか」を掲げて、**2011年**に**国立情報学研究所**（新井紀子らのチーム）が始めたプロジェクト。
- **結果**: 2016年の大学入試センター試験の模試で偏差値57.1。多くの私立大学で合格可能性80%以上の判定を得たが、東大合格圏には届かなかった。数学や世界史は得意だが、**国語や英語の読解**のように文の意味や常識が必要な問題が苦手だった。
- **その後**: 2016年に「東大合格」を目標とするのはやめ、研究成果を中高生の**読解力**の調査（リーディングスキルテスト）などに生かす方向へ移った。
- **意味**: 当時のAIは文の意味を理解しているわけではない、ということを示した例（シンボルグラウンディング問題、01章）。

## 2-3 機械学習の台頭（第3次AIブームの前半）

第2次ブームの反省は「知識を人が書くのは無理がある」だった。1990年代以降、インターネットとともに使えるデータが増え、**知識やルールをデータから統計的に学ぶ**方式が主流になった。

### 機械翻訳の変遷（ルール → 統計 → ニューラル）

| 方式 | 時期 | 仕組み | 弱点 |
|---|---|---|---|
| **ルールベース機械翻訳（RMT）** | 1950年代〜 | 人が辞書と文法規則を書き、それに従って訳す | 例外や言い回しをすべて規則にするのは不可能。知識獲得のボトルネックと同じ問題 |
| 用例ベース機械翻訳 | 1980年代〜 | 対訳の**用例**の中から似た文を探して、それをもとに訳す。長尾真が提唱 | 用例が足りないと訳せない |
| **統計的機械翻訳（SMT）** | 1990年代〜（IBMの研究が出発点） | 大量の**対訳データ（コーパス）**から、「どの単語・句がどう訳されやすいか」を**確率**として学ぶ | 単語・句単位で訳すので、長い文の語順や文脈に弱い |
| ニューラル機械翻訳（NMT） | 2014年ごろ〜（2016年に Google 翻訳が採用） | ニューラルネットワークで文全体を変換する | → 06章 |

- **問われ方**: 「対訳データから確率的に訳す」→ 統計的機械翻訳。「人が規則を書く」→ ルールベース。

### データマイニングとウェブマイニング
- **データマイニング**: 大量のデータから、役に立つパターンや規則を**掘り出す**こと。有名な逸話に、スーパーの購買データから「紙おむつとビールが一緒に売れる」という意外な関係が見つかった、というものがある（実話かどうかは諸説あり、たとえ話として使われる）。
- **ウェブマイニング**: Web 上のデータ（ページの内容、リンクの構造、閲覧の履歴）を対象にしたデータマイニング。
- **関係**: これらで得た関係は、ライトウェイトオントロジーの材料にもなる。

### ビッグデータ
- **一言で**: インターネットやスマートフォン、センサーの普及で生まれた、**量が膨大で、種類が多様で、次々に発生する**データ。
- **3つのV**: Volume（量）、Variety（多様性）、Velocity（速度）。
- **意味**: 機械学習の性能はデータ量に大きく左右される。ビッグデータは、**第3次AIブームの3つの要因**（ビッグデータ・計算機の性能向上・ディープラーニング）の1つ（01章）。

### スパムフィルターとレコメンデーション（機械学習の初期の代表的な応用）

| 応用 | 何をするか | 機械学習としての分類 |
|---|---|---|
| **スパムフィルター** | 迷惑メールを自動で判定して振り分ける。人がキーワードのルールを書く方式から、迷惑メールと普通のメールの実例から学ぶ方式（単純ベイズ分類器など）に変わり、精度が上がった | 分類（教師あり学習） |
| **レコメンデーション** | 利用者の好みに合う商品・コンテンツを薦める | 協調フィルタリング（似た利用者の行動を使う）／コンテンツベースフィルタリング（商品の特徴を使う） |

- どちらも、AIのレベル分類のレベル3（機械学習を取り入れたAI）の代表例。協調フィルタリングなどの詳細は03章。

### 特徴抽出と次元の呪い（機械学習の壁）
- **特徴量**: 予測の手がかりになる数値。例えば、迷惑メールなら「特定の単語の出現回数」、顔画像なら「目と目の距離」。
- **特徴抽出**: データから特徴量を取り出すこと。従来の機械学習では、**何を特徴量にするかを人が設計**していた（特徴量エンジニアリング）。良い特徴量を見つけられるかどうかで性能が決まり、ここが人の手に頼る**新たなボトルネック**になった。
- **次元の呪い**: 特徴量の数（次元）を増やすと、データ空間が指数関数的に広がり、同じ精度を出すのに必要なデータ量が爆発的に増える現象（数学者ベルマンが命名）。特徴量を闇雲に増やすと、かえって性能が落ちる。
  - 対策: 重要な特徴量だけを選ぶ（特徴選択）、次元削減（主成分分析など、→ 03章）。
- **ここからの流れ**: 「特徴量をどう設計するか」という壁を、**特徴量そのものをデータから学ぶ**ディープラーニング（特徴表現学習、→ 04章）が越えていく。

## 2-4 ディープラーニングの台頭

### 人間の神経回路とニューラルネットワーク
- **人間の神経回路**: 脳は膨大な数の**ニューロン（神経細胞）**でできている。ニューロンは樹状突起で他の細胞からの信号を受け取り、合計がある量（しきい値）を超えると、軸索を通じてシナプスの先の細胞に信号を送る。
- **ニューラルネットワーク**: この仕組みを数式でまねたもの。
  - 1943年 **形式ニューロン**（マカロックとピッツ）: 入力の重み付きの合計がしきい値を超えたら1を出す、という神経細胞のモデル。
  - 1958年 **パーセプトロン**（ローゼンブラット）: 形式ニューロンに「学習」を加えたもの（→ 04章）。
- **視覚の研究**: ヒューベルとウィーゼルが、ネコの脳の視覚野に、特定の向きの線に反応する**単純型細胞**と、位置が少しずれても反応する**複雑型細胞**があることを発見した（1959年〜1960年代、1981年にノーベル生理学・医学賞）。これがネオコグニトロンや CNN の発想の元になった。

### ネオコグニトロン
- **一言で**: **1980年**に **福島邦彦**（NHK放送科学基礎研究所）が発表した、視覚のパターン認識のためのニューラルネットワーク。**CNN の原型**。
- **仕組み**: 単純型細胞をまねた **S細胞の層**（特徴を取り出す）と、複雑型細胞をまねた **C細胞の層**（位置のずれを吸収する）を**交互に重ねた**構造。それぞれ、CNN の**畳み込み層**と**プーリング層**に相当する。
- **LeNet との違い**: ネオコグニトロンは誤差逆伝播法ではなく、**自己組織化**的な方法（教師なしの学習則）で学習した。
- **問われ方**: 「CNN の原型を提案した日本人研究者」→ 福島邦彦。

### LeNet
- **一言で**: **ヤン・ルカン**（当時は AT&T ベル研究所）が開発した CNN。1989年に**誤差逆伝播法で学習する CNN** として郵便番号の手書き数字の認識に使われ、**1998年**に発表された **LeNet-5** が代表的な形。
- **構造**: 畳み込み層 → プーリング（サブサンプリング）層 → … → 全結合層。現在の CNN の基本形（→ 05章）。
- **ネオコグニトロンとの違い**: 構造は似ているが、**誤差逆伝播法**で学習する点が違う。
- **実用**: 銀行の小切手の数字の読み取りなどに実際に使われた。

### CNN（畳み込みニューラルネットワーク）
- **一言で**: 画像の小さな領域ごとにフィルタを当てて特徴を取り出す**畳み込み層**を持つニューラルネットワーク。画像認識の主役。
- この章では「ネオコグニトロン → LeNet → AlexNet」という**歴史の流れ**だけを押さえる。仕組み（畳み込み、プーリング、ストライドなど）は05章、代表的なモデルは06章。

### 2006年: ディープラーニングの始まり
- **ジェフリー・ヒントン**らが、**ディープビリーフネットワーク**や**オートエンコーダ**を使って1層ずつ**事前学習**することで、深いネットワークを学習できることを示した（→ 04章、05章）。
- それまでは、層を深くすると勾配消失（→ 04章）で学習がうまく進まなかった。

### ImageNet
- **一言で**: スタンフォード大学（当時はプリンストン大学）の **フェイフェイ・リー** らが作った、大規模な画像データセット。2009年に発表され、約1,400万枚の画像に、2万以上のカテゴリのラベルが付いている。
- **なぜ重要か**: 「アルゴリズムだけでなく、**大量のラベル付きデータ**こそが性能を決める」という考えで作られ、ディープラーニングが力を発揮する土台になった。ラベル付けにはクラウドソーシング（Amazon Mechanical Turk）が使われた。

### ILSVRC（ImageNet Large Scale Visual Recognition Challenge）
- **一言で**: ImageNet の一部（**1,000クラス**、学習用に約120万枚）を使った画像認識の競技会。**2010年〜2017年**に開催された。
- **2012年の衝撃**: トロント大学の **ヒントン** のチーム（クリジェフスキー、サツケバー）の **AlexNet**（CNN、GPUで学習）が、エラー率（上位5つに正解が含まれない割合）**15.3%** で優勝した。2位（従来手法）の **26.2%** に**約10ポイント**もの差をつけた。
  - それまでの画像認識は、人が設計した特徴量に機械学習を組み合わせる方式で、毎年1〜2ポイントずつしか改善しなかった。
- **その後**: 優勝チームはディープラーニングを使うのが当たり前になった。2015年には ResNet がエラー率3.57%を出し、人間の目安（約5.1%）を下回った（→ 06章）。
- **同じ2012年**: Google の研究チーム（アンドリュー・ン、ジェフ・ディーンら）が、YouTube から集めた約1,000万枚の画像を、16,000個の CPU コアを使って**教師なし**で学習させたところ、ネコの顔に反応するニューロンが自然にできた（**Google の猫**）。
- **問われ方**: 「2012年」「ヒントン」「トロント大学」「AlexNet」「ILSVRC」の組み合わせ。LeNet（ルカン、1998年）との取り違え。

### AlphaGo（アルファ碁）
- **一言で**: Google 傘下の **DeepMind**（2014年に Google が買収）が開発した囲碁AI。
- **年表**:
  - 2015年10月: ヨーロッパ王者のプロ棋士 **樊麾（ファン・フイ）** に5戦全勝。プロ棋士にハンディなしで勝った**初めての**囲碁AI（発表は2016年1月）。
  - **2016年3月**: 世界トップ棋士の **イ・セドル** に **4勝1敗**。
  - 2017年5月: 世界ランク1位の **柯潔（カ・ケツ）** に3連勝し、対局からの引退を発表。
  - 2017年10月: 人間の棋譜を使わず、自己対戦だけで学習した **AlphaGo Zero** を発表。
- **技術**: ディープラーニング（盤面を評価する CNN）＋ **強化学習**（自己対戦）＋ **モンテカルロ木探索**（2-1）。詳細は06章。
- **意味**: 囲碁は探索空間が最も大きく、「AIが人間に勝つのは10年以上先」と言われていた。第3次ブームを一般に印象づけた出来事。

### LLM（大規模言語モデル）
- **一言で**: 膨大な文章で学習し、「次に来る単語」を予測することで、文章の生成・要約・翻訳・質問応答などを1つのモデルでこなす言語モデル。
- **流れ**: 2017年の Transformer → GPT シリーズ・BERT → **2022年11月の ChatGPT** の公開で一般に普及。ワトソン（2011年）の時代の「質問応答」や、統計的機械翻訳の「確率で言葉を扱う」流れの延長にあり、それらを大きく上回る性能を出した。
- 仕組みと課題（ハルシネーションなど）は06章で扱う。

### 近年の評価（2018〜2024年）
- **2018年度のチューリング賞**（2019年発表）: ディープラーニングへの貢献で、**ヒントン**、**ルカン**、**ヨシュア・ベンジオ**の3人が受賞。
- **2024年のノーベル物理学賞**: ニューラルネットワークによる機械学習の基礎を築いたとして、**ジョン・ホップフィールド**と**ヒントン**が受賞。
- **2024年のノーベル化学賞**: タンパク質の立体構造を予測する **AlphaFold** を開発した DeepMind の **デミス・ハサビス**と**ジョン・ジャンパー**が、タンパク質設計の**デイヴィッド・ベイカー**とともに受賞。

**数値**
- ハノイの塔の最小手数 ＝ **2ⁿ − 1**（3枚→7回、4枚→15回）
- 探索空間の目安: オセロ10⁶⁰、チェス10¹²⁰、将棋10²²⁰、囲碁10³⁶⁰
- AlexNet のエラー率 **15.3%**（2位は26.2%）

**対応関係**
- 幅優先 → 最短経路を保証、メモリ大／深さ優先 → メモリ小、最短の保証なし
- ミニマックス法 → αβ法（枝刈りで効率化、結果は同じ）→ モンテカルロ法（ランダムなプレイアウトの勝率で評価、評価関数が不要）
- is-a → 「〜の一種」、継承、推移律が成り立つ／part-of → 「〜の一部」／has-a → part-of の逆向き
- ヘビーウェイトオントロジー → 人が厳密に（Cyc）／ライトウェイトオントロジー → データから自動で（ワトソン）
- ルールベース機械翻訳 → 人が規則を書く／統計的機械翻訳 → 対訳データから確率を学ぶ
- ネオコグニトロン（自己組織化で学習）／LeNet（誤差逆伝播法で学習）

**ひっかけ注意**
- 世界初のエキスパートシステムは MYCIN ではなく **DENDRAL**。
- αβ法はミニマックス法と**同じ手**を選ぶ。精度を上げる手法ではなく、計算を減らす手法。
- ワトソンは質問の意味を「理解」しているわけではない。
- AlphaGo が初めてプロ棋士に勝ったのは2015年（樊麾）、トップ棋士イ・セドルに勝ったのは2016年。
- CNN の原型（ネオコグニトロン）を作ったのは福島邦彦。ルカンは LeNet。
