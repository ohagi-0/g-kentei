# 03 機械学習の概要

> ディープラーニング以前からある「古典的な」機械学習の手法と、モデルの評価方法の章。評価指標は**計算問題**として出るので、混同行列から自分で数字を出せるようにしておく。04章以降の土台にもなる。

## この章で押さえること

- 機械学習は **教師あり学習（回帰・分類）／教師なし学習（クラスタリング・次元削減など）／強化学習** の3つに分かれる。問題文の「正解ラベルがあるか」「報酬で学ぶか」で見分ける。
- 教師あり学習は手法名と**用途（回帰か分類か）**の対応、アンサンブル学習は**バギング（並列）とブースティング（直列）**の違いがよく問われる。
- 強化学習は **探索と利用のトレードオフ**、**価値ベース（Q学習）と方策ベース（方策勾配法）** の対比が軸。
- 評価は、**混同行列 → 正解率・適合率・再現率・F値**の計算、**MSE・RMSE・MAE** の違い、**ホールドアウトと交差検証**、**過学習と未学習** の見分けが頻出。

## 全体像: 機械学習の地図

```
機械学習
 ├─ 教師あり学習（正解ラベル付きのデータで学ぶ）
 │    ├─ 回帰（数値を予測）… 線形回帰、重回帰分析、AR/VAR、（決定木・SVMなども回帰に使える）
 │    └─ 分類（カテゴリを予測）… ロジスティック回帰、SVM、決定木、k近傍法
 │         └─ アンサンブル学習 … バギング（ランダムフォレスト）、ブースティング（AdaBoost、勾配ブースティング）
 │
 ├─ 教師なし学習（正解ラベルなしで、データの構造を見つける）
 │    ├─ クラスタリング … k-means法（階層なし）、ウォード法＋デンドログラム（階層あり）
 │    ├─ 次元削減 … 主成分分析（PCA）、特異値分解（SVD）、多次元尺度構成法（MDS）、t-SNE
 │    ├─ トピックモデル … 潜在的ディリクレ配分法（LDA）
 │    └─ （推薦）協調フィルタリング、コンテンツベースフィルタリング
 │
 └─ 強化学習（試行錯誤し、報酬が最大になる行動を学ぶ）
      ├─ 枠組み … エージェント・環境・状態・行動・報酬、マルコフ決定過程、割引率
      ├─ 探索と利用 … バンディットアルゴリズム、ε-greedy方策、UCB方策
      ├─ 価値ベース … 状態価値関数、行動価値関数（Q関数）、Q学習
      └─ 方策ベース … 方策勾配法、REINFORCE、Actor-Critic

モデルの評価（すべてに共通）
 ├─ データの分け方 … 訓練／検証／テスト、ホールドアウト検証、k-分割交差検証
 ├─ 分類の指標 … 混同行列、正解率・適合率・再現率・F値、ROC曲線・AUC
 ├─ 回帰の指標 … MSE、RMSE、MAE
 ├─ うまく学べたか … 過学習・未学習、訓練誤差・汎化誤差、汎化性能
 └─ モデルの選び方 … AIC、BIC、オッカムの剃刀
```

## 3-1 機械学習の種類

### 機械学習とは
- **一言で**: 人がルールを書く代わりに、**データから規則性を自動で見つけて**予測・判断する技術。
- **なぜ**: エキスパートシステム（02章）のように人が知識をルールとして書き込む方式は、知識の量が増えると書き切れなくなった（知識獲得のボトルネック、01章）。データから学べば、ルールを書く手間を省ける。
- **ディープラーニングとの違い**: 従来の機械学習では、予測の手がかりになる**特徴量**（身長・体重・単語の出現回数など）を**人が設計する**。ディープラーニングは特徴量の設計まで自動で行う（特徴表現学習、04章）。

### 教師あり学習・教師なし学習・強化学習

| | 学習に使うもの | 目的 | 代表的なタスク・手法 |
|---|---|---|---|
| **教師あり学習** | 入力と**正解ラベル**の組 | 入力から正解を当てる | 回帰（線形回帰）、分類（ロジスティック回帰、SVM） |
| **教師なし学習** | 入力だけ（**正解なし**） | データに隠れた構造・まとまりを見つける | クラスタリング（k-means）、次元削減（PCA） |
| **強化学習** | 行動の結果として得る**報酬** | 長い目で見て報酬の合計が最大になる行動を学ぶ | Q学習、方策勾配法 |

- 中間的なものに、少量のラベル付きデータと大量のラベルなしデータを併用する**半教師あり学習**、データ自身から疑似的な正解を作って学ぶ**自己教師あり学習**がある（→ 06章）。
- **問われ方**: 「次のうち教師なし学習はどれか」→ クラスタリング・次元削減。「分類」と「クラスタリング」の取り違えがひっかけの定番。**分類は教師あり**（カテゴリが事前に決まっている）、**クラスタリングは教師なし**（グループを自動で見つける）。

### 回帰問題と分類問題

| | 予測するもの | 例 | 代表的な手法 |
|---|---|---|---|
| **回帰問題** | 連続した**数値** | 売上、気温、家賃の予測 | 線形回帰、重回帰分析 |
| **分類問題** | **カテゴリ**（クラス） | スパム判定、犬か猫か、陽性か陰性か | ロジスティック回帰、SVM、決定木 |

- 分類のうち、答えが2種類なら**二値分類**、3種類以上なら**多クラス分類**（例: 0〜9の手書き数字認識は10クラス）。
- **スパムフィルター**は機械学習の分類の代表例として出る（迷惑メールか否かの二値分類）。
- **ひっかけ**: 「ロジスティック**回帰**」は名前に反して**分類**の手法。

### 用語: 説明変数・目的変数・特徴量
- **説明変数**: 予測の材料となる入力（例: 立地、曜日、天気）。機械学習では**特徴量**とも呼ぶ。
- **目的変数**: 予測したい対象（例: 売上）。教師あり学習の「正解ラベル」にあたる。

### 次元の呪い
- **一言で**: 特徴量の数（次元）が増えるほど、空間がすかすかになり、十分に学習するのに必要なデータ量が**指数関数的に**増えてしまう現象。
- **なぜ問題か**: 「特徴量を増やせば賢くなる」とは限らず、データが足りないと逆に精度が落ちる。
- **対策**: 役立つ特徴量だけ選ぶ（特徴選択・特徴抽出）、**次元削減**（3-4）でまとめる。

## 3-2 教師あり学習の手法

### 手法の早見表

| 手法 | 回帰／分類 | 一言で | キーワード |
|---|---|---|---|
| 線形回帰 | 回帰 | データに直線（平面）を当てはめる | 最小二乗法、単回帰・重回帰 |
| ロジスティック回帰 | **分類** | 線形の式の出力をシグモイド関数で0〜1の確率にする | 名前は回帰だが分類 |
| 自己回帰モデル（AR） | 回帰（時系列） | **自分自身の過去の値**から将来を予測 | 時系列データ |
| ベクトル自己回帰モデル（VAR） | 回帰（時系列） | **複数の時系列**の相互の影響まで含めて予測 | ARの多変数版 |
| サポートベクターマシン（SVM） | 主に分類（回帰も可） | 境界とデータの間の**余白（マージン）を最大**にする境界を引く | マージン最大化、カーネルトリック |
| 決定木 | 両方 | 「もし〜なら」の分岐を木の形で重ねる | 解釈しやすい、過学習しやすい |
| k近傍法（k-NN） | 主に分類（回帰も可） | 近い k 個のデータの**多数決**で決める | 学習らしい学習をしない、k-means と別物 |

### 線形回帰と重回帰分析
- **一言で**: y ＝ ax ＋ b のような**直線**でデータの関係を表し、数値を予測する。
- **直線の決め方**: 実際の値と直線のずれを**二乗して合計した値（二乗誤差）が最小**になるように a と b を決める。これを**最小二乗法**という（→ 08章）。
- **単回帰と重回帰**: 説明変数が**1つ**なら単回帰分析、**2つ以上**なら**重回帰分析**。重回帰では、どの説明変数がどれだけ効いているか（係数の大きさ）も読み取れる。
- **補足**: 線形回帰に L1／L2 正則化を加えたものがラッソ回帰／リッジ回帰（→ 04章 4-4）。説明変数どうしの相関が強すぎると係数が不安定になる（**多重共線性**）。

### ロジスティック回帰
- **一言で**: 線形回帰と同じく入力に重みを掛けて足すが、その結果を**シグモイド関数**に通して **0〜1の確率**に変換し、しきい値（通常0.5）で分類する。
- **なぜ**: 線形回帰の出力は−∞〜∞なので、そのままでは「陽性である確率」として使えない。シグモイド関数で0〜1に収めれば、確率として解釈でき、分類に使える。
- **多クラスへの拡張**: シグモイドの代わりに**ソフトマックス関数**を使う（多項ロジスティック回帰）。ニューラルネットワークの出力層と同じ発想（→ 04章 4-2）。
- **問われ方**: 「ロジスティック回帰は回帰に使う」→ 誤り。「出力に使う関数」→ シグモイド関数。

### 自己回帰モデル（AR）とベクトル自己回帰モデル（VAR）
- **AR**: 「先月・先々月の売上 → 来月の売上」のように、**1つの時系列の自分自身の過去の値**を説明変数にして将来を予測する。
- **VAR**: 売上・広告費・気温のように**複数の時系列**をまとめて（ベクトルとして）扱い、互いの影響も含めて全変数の将来を予測する。
- **違い**: 扱う時系列が1つか複数か。「広告費が翌月の売上にどう影響するか」まで見たいなら VAR。
- （補足）ディープラーニングで時系列を扱うのは RNN・LSTM（→ 05章）。

### サポートベクターマシン（SVM）
- **一言で**: 2つのクラスを分ける境界（**超平面**: 2次元なら直線、3次元なら平面）のうち、**最も近いデータまでの距離（マージン）が最大**になるものを選ぶ手法。
- **サポートベクトル**: 境界に**最も近い**データ点。境界の位置はこの少数の点だけで決まる（名前の由来）。
- **なぜマージンを最大にするか**: 境界がどちらかのクラスに寄っていると、新しいデータが少しずれただけで誤分類する。余白を最大にすると**汎化性能**が上がる。
- **ハードマージンとソフトマージン**: 一切の誤分類を許さないのがハードマージン。現実のデータはきれいに分けられないことが多いので、多少のはみ出しを許してペナルティを課す**ソフトマージン**が実用上の標準。
- **カーネルとカーネルトリック**:

| | 一言で | ポイント |
|---|---|---|
| **カーネル**（法） | 直線で分けられないデータを**高次元の空間に写す**と、平面で分けられるようになるという考え方 | 例: 平面上で「円の内側と外側」に分かれた点は、高さ（中心からの距離）の軸を足すと平面で切り分けられる |
| **カーネルトリック** | 高次元への変換を**実際には計算せず**、カーネル関数で「変換後のデータどうしの内積」だけを直接求める工夫 | 高次元（無限次元も可）でも計算量を抑えられる。代表的なカーネル関数は **RBF（ガウス）カーネル**、多項式カーネル |

- **歴史**: ヴァプニク（Vapnik）らが理論を築き、1990年代にソフトマージンとカーネル法で実用化。ディープラーニング以前は最有力の分類手法の1つだった。
- **問われ方**: 「SVMの説明として正しいもの」→ マージン最大化。「非線形な分類を可能にする工夫」→ カーネルトリック。

### 決定木
- **一言で**: 「年齢は30歳以上？」「収入は500万円以上？」のような条件で**データを次々と分岐**させ、末端（葉）で答えを出す。分類にも回帰にも使える。
- **分岐の決め方**: 分けた後のグループができるだけ「1つのクラスだけ」になる（**不純度**が下がる）条件を選ぶ。不純度の指標には**ジニ不純度**や**エントロピー**（情報利得）を使う。
- **長所**: 判断の過程が見えるので**説明しやすい**。特徴量のスケール（単位の違い）をそろえる前処理がほぼ不要。
- **短所**: 木を深くすると訓練データに合わせすぎて**過学習しやすい**。データが少し変わると木の形が大きく変わる（不安定）。
- **だから**: 多数の決定木を組み合わせる**ランダムフォレスト**や**勾配ブースティング**（3-3）が生まれた。

### k近傍法（k-NN）
- **一言で**: 新しいデータに**最も近い k 個**の訓練データを探し、その**多数決**でクラスを決める（回帰なら平均）。
- **特徴**: 事前に式を学習せず、訓練データを覚えておいて予測時に距離を計算する（怠惰学習）。k が小さいと外れ値に振り回されて過学習ぎみ、大きいと境界がぼやける。
- **ひっかけ**: **k近傍法は教師あり（分類）**、**k-means法は教師なし（クラスタリング）**。どちらも「k」と「距離」を使うが、別物。

## 3-3 アンサンブル学習

**アンサンブル学習**は、複数のモデル（**弱学習器**: 単体ではそれほど強くないモデル）を組み合わせ、多数決や平均で予測精度と安定性を高める手法。決定木の「過学習しやすく不安定」という弱点を補う形で発展した。

### バギングとブースティング

| | **バギング** | **ブースティング** |
|---|---|---|
| 学習の進め方 | **並列**（各モデルは独立） | **直列**（前のモデルの結果を見て次を作る） |
| 各モデルのデータ | ブートストラップサンプリングで作った別々のデータ | 前のモデルが**間違えたデータを重視** |
| 主に減らすもの | 予測の**ばらつき**（バリアンス）→ 過学習を抑える | 予測の**偏り**（バイアス）→ 精度を上げる |
| 速さ | 並列化できるので速い | 順番に学習するので時間がかかる |
| 精度 | 安定 | 高精度になりやすいが、やりすぎると過学習 |
| 代表例 | **ランダムフォレスト** | **AdaBoost**、**勾配ブースティング**（XGBoost、LightGBM） |

### ブートストラップサンプリング
- **一言で**: 元のデータから**重複を許して**（取り出したら元に戻して）ランダムに同じ数だけ取り出し、少しずつ違うデータセットを何組も作る方法。
- **数値の小ネタ**: データ数が十分大きいと、1組のサンプルに含まれる元データは約 **63%**（1 − 1/e）。残りの約37%は一度も選ばれず、性能の検証に使える（**OOB: Out-Of-Bag**）。

### ランダムフォレスト
- **一言で**: 多数の決定木を**バギング**で学習させ、分類なら**多数決**、回帰なら**平均**で予測する。
- **バギングとの違い（「ランダム」の意味）**: データをブートストラップでばらつかせるだけでなく、**分岐ごとに使う特徴量もランダムに一部だけ選ぶ**。こうすると木どうしが似すぎず（相関が下がり）、多数決の効果が大きくなる。
- **おまけ**: 各特徴量が予測にどれだけ効いたか（**特徴量の重要度**）を出せる。
- **歴史**: ブライマン（Breiman）が2001年に提案（バギングも同じブライマンが1996年に提案）。

### AdaBoost と勾配ブースティング

| | AdaBoost | 勾配ブースティング |
|---|---|---|
| 次のモデルに何を学ばせるか | 前のモデルが**誤分類したデータの重みを大きく**したデータ | 前のモデルまでの**誤差（残差）そのもの** |
| 統合の仕方 | 各モデルの性能に応じた重み付き多数決 | 各モデルの予測を少しずつ**足し合わせる** |
| 名前の由来 | Adaptive Boosting | 誤差（損失）を減らす方向＝**勾配**に沿って修正していくため |

- 勾配ブースティングを高速化した **XGBoost**、**LightGBM** は、表形式データ（テーブルデータ）の実務や Kaggle などのコンペで今も主力。

### 問われ方
- 「ランダムフォレストはバギングとブースティングのどちらか」→ **バギング**。
- 「誤分類したデータの重みを大きくする」→ AdaBoost。「誤差を次のモデルで学習」→ 勾配ブースティング。
- 「並列」「独立」→ バギング、「逐次」「直列」→ ブースティング。

## 3-4 教師なし学習の手法

### クラスタリング
- **一言で**: 正解ラベルなしで、似たデータどうしを**グループ（クラスタ）**にまとめる。例: 購買傾向による顧客の分類。
- **分類との違い**: 分類はカテゴリが**事前に決まっている**（教師あり）。クラスタリングはグループを**データから見つける**（教師なし）。できたグループが何を意味するかは人が解釈する。

| | **階層なしクラスタリング（非階層的）** | **階層ありクラスタリング（階層的）** |
|---|---|---|
| 代表例 | **k-means法** | **ウォード法**（ほかに最短距離法・最長距離法・群平均法など） |
| 進め方 | クラスタ数 k を**最初に決めて**、中心の更新を繰り返す | 近いものから順に**少しずつ統合**していく |
| 結果の表し方 | 各データの所属クラスタ | **デンドログラム**（樹形図） |
| クラスタ数 | 事前に人が決める | デンドログラムを**どの高さで切るか**で後から決められる |
| 大量データ | 計算が軽く向いている | 全データ間の距離を扱うので重い |

### k-means法（k平均法）
1. クラスタ数 **k を人が決め**、k 個の中心点をランダムに置く。
2. 各データを**最も近い中心**のクラスタに割り当てる。
3. 各クラスタの**平均（重心）**の位置に中心を移す。
4. 中心が動かなくなるまで 2〜3 を繰り返す。
- **弱点**: k を事前に決める必要がある。初期の中心の置き方で結果が変わる（改良版に k-means++）。球状でない形のクラスタは苦手。
- **問われ方**: 「k は自動で決まる」→ 誤り。「中心は各クラスタの平均」→ 正しい。

### ウォード法とデンドログラム
- **ウォード法**: 階層的クラスタリングの代表的な手法。2つのクラスタを統合したとき、**クラスタ内のばらつき（分散）の増え方が最も小さい**組み合わせから順に統合する。大きさのそろったクラスタになりやすい。
- **デンドログラム**: 統合の過程を木の形で描いた図。縦軸は統合したときの距離（似ていなさ）。**横に線を引く高さ**を変えると、クラスタ数を選べる。

### 次元削減
- **一言で**: 情報をなるべく失わずに、特徴量の数（次元）を減らすこと。
- **なぜ**: 次元の呪いの回避、計算の高速化、ノイズの除去、**2〜3次元にして目で見る（可視化）** ため。

| 手法 | 一言で | 線形／非線形 | 主な用途 |
|---|---|---|---|
| **主成分分析（PCA）** | データの**分散（散らばり）が最大**になる方向を第1主成分とし、それと直交する方向で次に分散が大きいものを第2主成分…と新しい軸を作る | 線形 | 次元削減全般、前処理 |
| **特異値分解（SVD）** | どんな行列も **A ＝ UΣVᵀ**（直交行列 × 特異値を並べた対角行列 × 直交行列）に分解する。大きい特異値の部分だけ残すと情報を圧縮できる | 線形 | 行列の圧縮、PCAの計算、推薦、文書解析（LSA） |
| **多次元尺度構成法（MDS）** | データどうしの**距離（似ていなさ）の関係をできるだけ保つ**ように低次元に配置する | 古典的MDSは線形 | 距離の表から地図のような配置図を作る |
| **t-SNE** | 高次元で**近いデータは近く**に置くことを重視して2〜3次元に配置する | **非線形** | **可視化専用**（例: MNISTの784次元を2次元に） |

- **PCA の用語**: 各主成分が元データの分散のうち何割を説明するかを**寄与率**、上位から足したものを**累積寄与率**という。「累積寄与率が80%になるまで主成分を残す」のように次元数を決める。
- **t-SNE の注意**: 2008年にファン・デル・マーテン（van der Maaten）とヒントンが提案。計算が重く、図の中のクラスタ間の距離や大きさには意味がないことが多いので、**可視化には向くが、ほかのモデルの前処理には向かない**。
- **問われ方**: 「分散が最大となる方向」→ PCA。「非線形の次元削減で可視化」→ t-SNE。「行列を3つの行列の積に分解」→ SVD。

### トピックモデルと潜在的ディリクレ配分法（LDA）
- **トピックモデル**: 文書に出てくる単語の組み合わせから、隠れた**話題（トピック）**を推定する教師なしの手法。
- **LDA**: 代表的なトピックモデル（ブレイら、2003年）。**1つの文書は複数のトピックの混合**（例: スポーツ7割・経済3割）、各トピックは単語の出現確率の分布、と考えて推定する。
- **ひっかけ**: 同じ略称の**線形判別分析（Linear Discriminant Analysis）**は、ラベルを使ってクラスを分けやすい軸を求める**教師あり**の手法で、別物。

### 推薦（レコメンデーション）の手法

| | **協調フィルタリング** | **コンテンツベースフィルタリング** |
|---|---|---|
| 使う情報 | **ほかのユーザーの行動履歴**（似た人が好きなもの） | **アイテム自体の特徴**（ジャンル、作者、価格帯など） |
| 例 | 「この商品を買った人はこんな商品も買っています」 | 「アクション映画をよく見る人に別のアクション映画を薦める」 |
| 長所 | アイテムの中身を知らなくても推薦できる。意外なアイテムも出せる | 新しいアイテムでも特徴さえわかれば推薦できる |
| 弱点 | **コールドスタート問題**に弱い | 似たものばかり薦めがち。特徴を用意する手間 |

- **コールドスタート問題**: 新規ユーザー（履歴がない）や新規アイテム（評価が少ない）について、データ不足で推薦できない問題。**協調フィルタリングの弱点**として問われる。対策としてコンテンツベースと組み合わせる（ハイブリッド）。

## 3-5 強化学習の基礎

### 強化学習の枠組み
- **一言で**: **エージェント**（行動する主体）が**環境**の中で**状態**を見て**行動**し、その結果として**報酬**を受け取る。これを繰り返し、**将来にわたる報酬の合計**が最大になる行動の選び方（**方策**）を学ぶ。
- **教師あり学習との違い**: 「この場面ではこの手が正解」という正解は与えられない。良し悪しは報酬でしかわからず、しかも報酬が**後から遅れて**届くことが多い（将棋の勝敗は最後にわかる）。
- ディープラーニングと組み合わせた深層強化学習（DQN、AlphaGo、PPO など）は → 06章。

### マルコフ決定過程（MDP）
- **一言で**: 次の状態と報酬が「**今の状態**」と「**今の行動**」だけで（確率的に）決まる、とみなす問題の定式化。強化学習の数学的な土台。
- **マルコフ性**: 未来は**現在だけ**に依存し、過去の経緯には依存しないという性質。
- **例**: すごろくで、次のマスは「今いるマス」と「振るサイコロ」だけで決まり、それまでの道のりは関係ない。

### 割引率（γ）
- **一言で**: 将来の報酬を、今の価値に換算するときに掛ける係数（**0〜1**）。1ステップ先は γ 倍、2ステップ先は γ² 倍…と遠いほど割り引く。
- **なぜ**: 目先の報酬と将来の報酬のどちらを重視するかを調整するため。終わりのない問題で報酬の合計が無限大になるのも防ぐ。
- **γが1に近い** → 将来を重視（長期的）、**0に近い** → 目先の報酬を重視（短期的）。
- **計算例**: γ ＝ 0.9 で、今・1ステップ後・2ステップ後に報酬1ずつもらえるなら、割引後の合計（**収益**）は 1 ＋ 0.9 ＋ 0.81 ＝ **2.71**。

### 状態価値関数と行動価値関数

| | 何の価値か | 記号 | 将棋でのたとえ |
|---|---|---|---|
| **状態価値関数** | ある**状態**から先、方策に従ったときに得られる割引報酬の合計の期待値 | V(s) | 今の盤面がどれだけ有利か |
| **行動価値関数** | ある状態で**ある行動をとった**ときの、その後の割引報酬の合計の期待値 | **Q(s, a)** | 今の盤面でこの一手を指したらどれだけ有利になるか |

- 行動価値関数の値を**Q値**、関数を**Q関数**と呼ぶ。Q値が最大の行動を選べば良い方策になる。

### 探索と利用のトレードオフとバンディットアルゴリズム
- **探索**: まだよく知らない選択肢を試して情報を集めること。**利用**: 今わかっている中で最良の選択肢を選んで報酬を得ること。探索ばかりだと損をし、利用ばかりだとより良い選択肢を見逃す。この両立の難しさが**探索と利用のトレードオフ**。
- **バンディットアルゴリズム**: 当たりやすさの違う複数のスロットマシン（バンディット）を限られた回数で引き、報酬を最大にする問題（**多腕バンディット問題**）を解く手法。状態の変化がない、強化学習の最も単純な形。Web広告の出し分け（A/Bテストの効率化）に使う。

| 方策 | 選び方 | 探索の仕方 |
|---|---|---|
| **ε-greedy方策** | 確率 **ε** でランダムに選び、残りの **1−ε** で今の最良（greedy＝欲張り）を選ぶ | ときどき**完全にランダム**に試す |
| **UCB方策** | 「これまでの平均報酬 ＋ **不確かさのボーナス**」が最大のものを選ぶ。試した回数が少ないほどボーナスが大きい | **まだよく知らない選択肢を優先して**試す |

- **計算例**: ε ＝ 0.1 なら、10回に1回はランダム、9回は最良と思うものを選ぶ。

### Q学習（価値ベース）
- **一言で**: 状態と行動の組ごとに**Q値の表（Qテーブル）**を持ち、行動して報酬を受け取るたびに Q値を更新していく手法（ワトキンス、1989年）。
- **更新のイメージ**: 新しいQ値 ＝ 今のQ値 ＋ 学習率 ×（**もらった報酬 ＋ γ × 次の状態での最大のQ値** − 今のQ値）。「実際に得た結果から見積もった値」と「今の予想」の差で少しずつ修正する。
- 行動の選択には ε-greedy方策などを使って探索する。
- **限界**: 状態や行動が多い（画像を状態とするなど）と表が巨大になって扱えない → Q関数をニューラルネットワークで近似したのが **DQN**（→ 06章）。

### 方策勾配法・REINFORCE・Actor-Critic（方策ベース）

| 手法 | 一言で | ポイント |
|---|---|---|
| **方策勾配法** | 方策（各行動を選ぶ確率）を**パラメータで表し、直接**最適化する | 行動が連続値（ロボットの関節角度など）でも扱える。確率的な方策を表せる |
| **REINFORCE** | 方策勾配法の最も基本的なアルゴリズム（ウィリアムズ、1992年） | 1回のエピソードを最後までやり、実際に得た報酬の合計で「良かった行動の確率を上げ、悪かった行動の確率を下げる」。更新のばらつきが大きい |
| **Actor-Critic** | 行動を選ぶ**Actor（方策）**と、その良し悪しを価値関数で評価する**Critic（価値）**を組み合わせる | 方策ベースと価値ベースのいいとこ取り。Critic の評価を使うので REINFORCE より更新が安定。発展形が A3C（→ 06章） |

- **価値ベースと方策ベースの違い**: 価値ベース（Q学習）は「各行動の価値」を学び、価値が最大の行動を選ぶ（方策は価値から間接的に決まる）。方策ベース（方策勾配法）は「どの行動をどれだけの確率で選ぶか」を直接学ぶ。
- **問われ方**: 「行動の選択肢が連続的で多いときに向く」→ 方策勾配法。「Actor と Critic の役割」→ Actor が行動を決め、Critic が評価する。

## 3-6 モデルの評価

### 過学習・未学習と汎化性能
- **汎化性能**: 学習に使っていない**未知のデータ**にどれだけ正しく対応できるか。機械学習の本当の目的。
- **訓練誤差**: 訓練データに対する誤差。**汎化誤差**: 未知のデータに対する誤差（実際にはテストデータの誤差で見積もる）。

| | 訓練誤差 | 汎化誤差 | 原因 | 対策 |
|---|---|---|---|---|
| **未学習**（学習不足） | **大きい** | **大きい** | モデルが単純すぎる、学習が足りない | モデルを複雑にする、特徴量を増やす、学習を続ける |
| ちょうどよい | 小さい | 小さい | — | — |
| **過学習** | **小さい** | **大きい**（差が開く） | モデルが複雑すぎる、データが少ない、ノイズまで覚えた | データを増やす、正則化・ドロップアウト・早期終了（→ 04章）、モデルを単純にする、アンサンブル |

```
誤差
 │＼                         ／ 汎化誤差（途中から上がる）
 │  ＼                   ／
 │    ＼＿＿＿＿＿＿＿／
 │     ＼
 │        ＼＿＿＿＿＿＿＿＿＿ 訓練誤差（下がり続ける）
 └──────────────────→ 学習の進み具合・モデルの複雑さ
   未学習   ちょうどよい   過学習
```

- **問われ方**: グラフを見て「どこから過学習か」→ **訓練誤差は下がり続けているのに、汎化（検証）誤差が上がり始めた所**。

### データの分け方: 訓練・検証・テスト

| データ | 何に使うか |
|---|---|
| **訓練データ** | モデルの重み（パラメータ）を学習する |
| **検証データ** | ハイパーパラメータの調整、モデルの選択、早期終了の判断 |
| **テストデータ** | 最後に1回だけ、**汎化性能を見積もる**。調整には使わない |

- テストデータを見ながら調整すると、テストデータに過学習して性能を高く見積もってしまう。評価用のデータが学習に混ざってしまうことを**データリーケージ**という（→ 07章）。

| 検証方法 | やり方 | 長所 | 短所 |
|---|---|---|---|
| **ホールドアウト検証** | データを学習用と評価用に**1回だけ**分ける（例: 8:2） | 手軽、計算が軽い | 分け方の運で結果がぶれる。評価用の分だけ学習データが減る |
| **k-分割交差検証** | データを **k 個**に分け、1つを評価用・残り k−1 個を学習用として、評価用を入れ替えながら **k 回**学習・評価し、**平均**をとる | 全データが1回ずつ評価に使われ、評価が安定。**データが少ないとき**に有効 | 学習を k 回行うので計算が k 倍 |

- **交差検証**は「分け方を変えて学習と評価を繰り返す」方法の総称で、k-分割交差検証はその代表。k は 5 や 10 がよく使われる。k をデータ数と同じにしたものが **1個抜き交差検証（LOOCV）**。
- **計算例**: データ1,000件で 5-分割交差検証なら、1回の評価用は 200件、学習用は 800件で、学習は **5回**行う。
- **注意**: 時系列データは、未来のデータで学習して過去を予測しないよう、**時間順を保って**分ける。

### 混同行列（計算問題が出る）

二値分類で、予測と正解の組み合わせを4マスに数えた表。「陽性（Positive）」は検出したい側（病気あり、スパムなど）。

|  | **予測: 陽性** | **予測: 陰性** |
|---|---|---|
| **実際: 陽性** | **TP**（真陽性）正しく陽性 | **FN**（偽陰性）**見逃し** |
| **実際: 陰性** | **FP**（偽陽性）**誤検知（空振り）** | **TN**（真陰性）正しく陰性 |

- **読み方のコツ**: 後ろの P／N は「**予測**が陽性か陰性か」、前の T／F は「その予測が**当たったか**」。FP ＝「陽性と予測したが外れ」＝実際は陰性。
- **統計の言葉との対応**（→ 08章の仮説検定）: 偽陽性（FP）＝**第一種の過誤**（あわてんぼうの誤り）、偽陰性（FN）＝**第二種の過誤**（ぼんやり者の誤り）。
- **ひっかけ**: 表の行と列（実際と予測）が入れ替わって出題されることがある。必ず見出しを確かめてから数える。

### 正解率・適合率・再現率・F値

| 指標 | 式 | 意味 | 分母になるもの |
|---|---|---|---|
| **正解率**（Accuracy） | (TP ＋ TN) ÷ 全体 | 全体のうち当たった割合 | 全データ |
| **適合率**（Precision） | TP ÷ (TP ＋ FP) | 陽性と**予測した**もののうち、本当に陽性だった割合（**誤検知の少なさ**） | 予測が陽性の列 |
| **再現率**（Recall） | TP ÷ (TP ＋ FN) | 本当に陽性のもののうち、陽性と当てられた割合（**見逃しの少なさ**）。**真陽性率**、感度ともいう | 実際が陽性の行 |
| **F値**（F1スコア） | 2 × 適合率 × 再現率 ÷ (適合率 ＋ 再現率) | 適合率と再現率の**調和平均**。両者のバランス | — |

- **覚え方**: 適合率は「予測（自分の判定）を信じてよいか」、再現率は「本物をどれだけ拾えたか」。分母が**予測側**なら適合率、**実際側**なら再現率。
- 適合率と再現率は**トレードオフ**: 陽性と判定するしきい値を下げると、見逃しが減って再現率は上がるが、誤検知が増えて適合率は下がる。

**計算例1: がん検診（不均衡なデータ）**

1,000人を検査。実際にがんの人は50人、がんでない人は950人。

|  | 予測: 陽性 | 予測: 陰性 | 合計 |
|---|---|---|---|
| 実際: 陽性（がん） | TP ＝ 40 | FN ＝ 10 | 50 |
| 実際: 陰性 | FP ＝ 60 | TN ＝ 890 | 950 |
| 合計 | 100 | 900 | 1,000 |

- 正解率 ＝ (40 ＋ 890) ÷ 1,000 ＝ **0.93**（93%）
- 適合率 ＝ 40 ÷ (40 ＋ 60) ＝ 40 ÷ 100 ＝ **0.40**（陽性と判定された人のうち、本当にがんは4割）
- 再現率 ＝ 40 ÷ (40 ＋ 10) ＝ 40 ÷ 50 ＝ **0.80**（がんの人の8割を見つけた）
- F値 ＝ 2 × 0.40 × 0.80 ÷ (0.40 ＋ 0.80) ＝ 0.64 ÷ 1.20 ≒ **0.53**

**ここが重要（正解率の落とし穴）**: 全員を「陰性」と判定するだけのモデルでも、正解率は 950 ÷ 1,000 ＝ **0.95** で、上のモデル（0.93）より高くなる。しかし再現率は **0**（がんを1人も見つけられない）。陽性と陰性の数が大きく偏った**不均衡データ**では、正解率だけで評価してはいけない。

**計算例2: 練習問題（自分で解いてから確認）**

100件のデータで、TP ＝ 30、FP ＝ 10、FN ＝ 20、TN ＝ 40 のとき、正解率・適合率・再現率・F値は？

**答え**
- 正解率 ＝ (30 ＋ 40) ÷ 100 ＝ **0.70**
- 適合率 ＝ 30 ÷ (30 ＋ 10) ＝ **0.75**
- 再現率 ＝ 30 ÷ (30 ＋ 20) ＝ **0.60**
- F値 ＝ 2 × 0.75 × 0.60 ÷ (0.75 ＋ 0.60) ＝ 0.90 ÷ 1.35 ≒ **0.67**

**なぜF値は「調和平均」なのか**
- 適合率 1.0、再現率 0.1 のモデル（ほとんど陽性と言わない慎重すぎるモデル）を考える。普通の平均（算術平均）なら 0.55 と、そこそこ良く見えてしまう。
- 調和平均なら 2 × 1.0 × 0.1 ÷ 1.1 ≒ **0.18**。**どちらか一方が低いと F値も低くなる**ので、片方だけ高いモデルを見抜ける。

**どの指標を重視するか**

| 場面 | 重視する指標 | 理由 |
|---|---|---|
| がん検診、不正取引の検知、製品の欠陥検査 | **再現率** | 見逃し（FN）の損害が大きい。多少の誤検知は再検査で補える |
| 迷惑メールフィルタ、検索結果、おすすめ | **適合率** | 誤検知（FP）の損害が大きい。大事なメールを迷惑メール扱いすると困る |
| 両方とも大事 | **F値** | バランスを1つの数値で比べたい |
| クラスの数が均衡している | 正解率でも可 | 不均衡データでは使わない |

### ROC曲線とAUC
- **ROC曲線**: 陽性と判定する**しきい値を変えながら**、横軸に**偽陽性率（FPR）**、縦軸に**真陽性率（TPR ＝ 再現率）**をとって点を結んだ曲線。
  - 偽陽性率 ＝ FP ÷ (FP ＋ TN)（実際は陰性のもののうち、陽性と誤判定した割合）。計算例1なら 60 ÷ 950 ≒ 0.063。
  - （参考）1 − 偽陽性率 を**特異度**という（陰性を正しく陰性と判定できた割合）。
- **AUC**（Area Under the Curve）: ROC曲線の**下側の面積**。0〜1の値をとる。

| AUC | 意味 |
|---|---|
| **1.0** | 完全に分類できる理想のモデル（曲線が左上の角を通る） |
| **0.5** | **ランダムな当てずっぽうと同じ**（曲線が対角線になる） |
| 0.5未満 | ランダムより悪い（判定を逆にした方がよい） |

- **長所**: しきい値を1つに決めなくても、モデルの判別能力そのものを比べられる。
- **問われ方**: 「ROC曲線が**左上**に膨らむほど良い」「AUC ＝ 0.5 はランダム」「ROC曲線の横軸・縦軸は何か」。
- （補足）陽性が極端に少ない不均衡データでは、縦軸に適合率・横軸に再現率をとる **PR曲線** の方が差が見えやすい。

### 回帰の評価指標: MSE・RMSE・MAE

| 指標 | 計算 | 単位 | 外れ値の影響 |
|---|---|---|---|
| **MSE**（平均二乗誤差） | 誤差を**二乗**して平均 | 元の単位の**二乗**（円²など） | **大きい**（大きな外れを強く罰する） |
| **RMSE**（平均二乗誤差の平方根） | MSE の**平方根** | **元の単位**に戻る | 大きい（MSEと同じ性質） |
| **MAE**（平均絶対誤差） | 誤差の**絶対値**を平均 | 元の単位 | **小さい**（すべての誤差を同じ重みで扱う） |

- どれも**0に近いほど良い**。MSE は誤差関数としても使う（→ 04章 4-3）。

**計算例: 外れ値があるとどう変わるか**

4件の予測について、誤差（予測 − 実際）が次のようになった。

| | 誤差 | MAE | MSE | RMSE |
|---|---|---|---|---|
| モデルA | 2, −2, 2, −2 | (2＋2＋2＋2) ÷ 4 ＝ **2** | (4＋4＋4＋4) ÷ 4 ＝ **4** | √4 ＝ **2** |
| モデルB | 0, 0, 0, 8 | (0＋0＋0＋8) ÷ 4 ＝ **2** | (0＋0＋0＋64) ÷ 4 ＝ **16** | √16 ＝ **4** |

- MAE は同じ2だが、1件だけ大きく外したモデルBは RMSE が2倍になる。**大外しを避けたいなら MSE／RMSE、外れ値に振り回されたくないなら MAE** で評価する。
- いつでも **MAE ≦ RMSE** が成り立つ（等しくなるのは、誤差の大きさが全部同じとき）。

### モデルの選び方: AIC・BIC・オッカムの剃刀

**オッカムの剃刀**
- **一言で**: 同じくらいうまく説明できるなら、**より単純な仮説（モデル）を選べ**という考え方。14世紀の哲学者オッカムのウィリアムにちなむ。
- **機械学習での意味**: 複雑なモデルは訓練データには合うが過学習しやすい。同程度の性能ならパラメータの少ないモデルが望ましい。これを数値化したのが AIC・BIC。

| | **AIC**（赤池情報量規準） | **BIC**（ベイズ情報量規準） |
|---|---|---|
| 考案者 | **赤池弘次**（日本の統計学者、1973年） | シュワルツ（1978年） |
| 式のイメージ | −2 ×（当てはまりの良さ）＋ **2 × パラメータ数** | −2 ×（当てはまりの良さ）＋ **log(データ数) × パラメータ数** |
| 複雑さへの罰 | 比較的ゆるい | **より厳しい**（データ数が8件以上ならAICより重い罰。データが多いほど厳しくなる） |
| 選ばれやすいモデル | 予測の良さを重視し、やや複雑なモデルも選ぶ | より**単純な**モデル |
| 良し悪し | **値が小さいほど良い** | **値が小さいほど良い** |

- 「当てはまりの良さ」は最大対数尤度（→ 08章の最尤法）。当てはまりが良いほど第1項が小さくなり、パラメータが多いほど第2項が大きくなる。
- **問われ方**: 「AIC は大きいほど良い」→ 誤り。「AIC と BIC で、複雑なモデルにより厳しいのは」→ BIC。「AIC を考案したのは」→ 赤池弘次。

## 章末まとめ（暗記必須）

**人物・年号**
- 赤池弘次 → **AIC**（1973）／シュワルツ → BIC（1978）／オッカム（14世紀）→ オッカムの剃刀
- ブライマン → バギング（1996）、**ランダムフォレスト（2001）**
- ヴァプニク → SVM／ワトキンス → Q学習（1989）／ウィリアムズ → REINFORCE（1992）
- ファン・デル・マーテンとヒントン → t-SNE（2008）／ブレイら → LDA（2003）

**数値・計算**
- 正解率 ＝ (TP＋TN) ÷ 全体／適合率 ＝ TP ÷ (TP＋FP)／再現率 ＝ TP ÷ (TP＋FN)
- F値 ＝ 2 × 適合率 × 再現率 ÷ (適合率 ＋ 再現率)（調和平均）
- 偽陽性率 ＝ FP ÷ (FP＋TN)／ROC曲線は横軸 偽陽性率・縦軸 真陽性率（再現率）
- AUC: 1.0 が理想、**0.5 はランダム**
- RMSE ＝ √MSE、MAE ≦ RMSE
- 割引率 γ は 0〜1。γ ＝ 0.9 なら報酬は 1, 0.9, 0.81… と割り引かれる
- k-分割交差検証: 学習・評価を **k 回**、1回の評価用データは全体の 1/k
- ブートストラップサンプルに含まれる元データは約 63%

**対応関係**
- 回帰 → 数値／分類 → カテゴリ／ロジスティック回帰は**分類**
- 単回帰 → 説明変数1つ／重回帰 → 2つ以上／AR → 1つの時系列／VAR → 複数の時系列
- SVM → マージン最大化、サポートベクトル、カーネルトリック
- バギング → 並列・ばらつきを減らす・ランダムフォレスト／ブースティング → 直列・間違いを重視・AdaBoost、勾配ブースティング
- k-means → 階層なし・k を事前に決める／ウォード法 → 階層あり・デンドログラム
- PCA → 分散最大の方向／t-SNE → 非線形・可視化／SVD → A ＝ UΣVᵀ／MDS → 距離関係を保つ
- 協調フィルタリング → ほかのユーザーの行動・コールドスタート問題に弱い／コンテンツベース → アイテムの特徴
- ε-greedy → 確率εでランダム／UCB → 不確かさにボーナス
- 価値ベース → Q学習／方策ベース → 方策勾配法・REINFORCE／両方 → Actor-Critic
- 見逃しが怖い → 再現率／誤検知が怖い → 適合率
- 外れ値に強い → MAE／大外しを強く罰する → MSE・RMSE
- AIC・BIC → どちらも**小さいほど良い**、BIC の方が単純なモデルを選ぶ

**ひっかけ注意**
- 「ロジスティック回帰」は分類の手法。
- 「分類」は教師あり、「クラスタリング」は教師なし。
- k近傍法（教師あり・分類）と k-means法（教師なし・クラスタリング）は別物。
- LDA は「潜在的ディリクレ配分法（トピックモデル）」と「線形判別分析」の2つがある。
- 不均衡データでは正解率が高くても良いモデルとは限らない。
- 混同行列の行と列（実際／予測）が入れ替わった出題に注意。
- 過学習は「訓練誤差が小さく汎化誤差が大きい」。両方大きいのは未学習。
- テストデータはハイパーパラメータの調整に使わない（それは検証データの役目）。
