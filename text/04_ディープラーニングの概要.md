# 04 ディープラーニングの概要

> 重点分野。学習の「仕組み」の章で、05（要素技術）・06（応用例）を読むための土台になる。

## この章で押さえること

- ニューラルネットワークは **「順伝播で予測 → 誤差関数でずれを測る → 誤差逆伝播法で勾配を求める → 最適化手法で重みを更新」** を繰り返して学習する。章の全トピックがこの1サイクルのどこかに当てはまる。
- 層を深くするほど表現力は上がるが、**勾配消失**と**過学習**が起きやすくなる。この2つをどう防ぐかが、この章の多くの手法が生まれた理由。
- 試験では、**活性化関数の出力範囲と用途**、**L1とL2の違い**、**最適化手法の系譜（AdaGrad→RMSProp→Adam）** がよく問われる。

## 全体像: 学習の1サイクル

```
 入力データ
    │
    ▼
[順伝播]  入力層 → 隠れ層（活性化関数）→ 出力層（ソフトマックス等）
    │
    ▼
[誤差関数]  予測と正解のずれを数値化（MSE・交差エントロピー）
    │
    ▼
[誤差逆伝播法]  連鎖律で、各重みの勾配を出力側から順に計算
    │           └ 問題: 勾配消失・勾配爆発
    ▼
[最適化手法]  勾配を使って重みを更新（SGD・モーメンタム・Adam）
    │
    └──→ 次のミニバッチへ（これを何エポックも繰り返す）

 並行して: 過学習を防ぐ → 正則化（L1/L2・ドロップアウト・早期終了）
```

## 4-1 ニューラルネットワークとディープラーニング

### 歴史の流れ（なぜ「深く」できるようになったか）

| 年 | 出来事 | 意味 |
|---|---|---|
| 1958 | ローゼンブラットが**単純パーセプトロン**を提案 | 学習する人工ニューロンの始まり |
| 1969 | ミンスキーとパパートが、単純パーセプトロンは**XORを解けない**（線形分離不可能な問題を扱えない）ことを指摘 | ニューラルネットワーク研究が下火に |
| 1986 | ラメルハートらが**誤差逆伝播法**を広める | 多層パーセプトロンを学習できるようになる |
| 1990年代 | 層を深くすると**勾配消失**で学習が進まない | 再び停滞 |
| 2006 | ヒントンらが**事前学習**（ディープビリーフネットワーク、オートエンコーダ）で深い層の学習に成功 | ディープラーニングの始まり |
| 2012 | ヒントンのチームの AlexNet が ILSVRC で圧勝（GPUを使用） | 第3次AIブームの決定打 |

その後は ReLU、良い重みの初期値、バッチ正規化、スキップ結合（05章）などが整い、事前学習なしでも深いネットワークを学習できるようになった。

### 単純パーセプトロン
- **一言で**: 入力層と出力層だけのネットワーク。入力に重みを掛けて足し、バイアスを加え、しきい値で0/1を出す。
- **限界**: **線形分離可能な問題しか解けない**。直線1本で分けられないXORが代表例。
- **問われ方**: 「単純パーセプトロンで解けない問題はどれか」→ XOR（線形分離不可能）。

### 多層パーセプトロン（MLP）と入力層・隠れ層・出力層
- **一言で**: 入力層と出力層の間に**隠れ層**を挟んだネットワーク。
- **なぜ**: 隠れ層と非線形の活性化関数を加えることで、**非線形な境界**（XORなど）を表現できるようになる。
- **ディープラーニングとの関係**: 隠れ層を何層も重ねた（深くした）ニューラルネットワークを使う機械学習が**ディープラーニング**。
- **補足**: 隠れ層が1層でも、ユニット数を十分増やせば任意の連続関数を近似できる（万能近似定理）。それでも深くするのは、層を重ねると「エッジ → 形 → 物体」のように特徴を段階的に組み立てられ、少ないパラメータで複雑な表現ができるため。

### 重みとバイアス
- **重み**: 各入力の重要度。学習で調整されるパラメータの中心。
- **バイアス**: 入力が全部0でも出力を調整できる切片。重みと一緒に学習される。
- **ハイパーパラメータとの違い**: 重み・バイアスは**学習で自動的に決まる**。学習率や層の数などは**人が事前に決める**（4-6）。

### 特徴表現学習
- **一言で**: 予測に役立つ特徴量を、データから**自動で**学ぶこと。
- **なぜ重要か**: 従来の機械学習は、人が特徴量を設計していた（特徴量エンジニアリング）。ディープラーニングは特徴量の設計まで学習に任せられる点が最大の違い。
- **問われ方**: 「ディープラーニングが従来の機械学習と大きく異なる点は」→ 特徴量を自動で獲得する（特徴表現学習）。

### CPU・GPU・TPU

| | 得意なこと | ディープラーニングでの位置づけ |
|---|---|---|
| CPU | 複雑な処理を**順番に**こなす汎用プロセッサ | 全体の制御。大量の行列計算には不向き |
| GPU | 単純な計算を**大量に並列**で行う。元は画像処理用 | 行列計算が速く、学習の主役。画像処理以外の計算に使うことを **GPGPU** という（NVIDIAのCUDAが代表） |
| TPU | Googleが開発した**機械学習（テンソル計算）専用**のプロセッサ | GPUより特化していて、電力効率が高い |

- **問われ方**: 「ディープラーニングの学習にGPUが向く理由」→ 行列演算を**並列処理**できるから。「TPUを開発した企業」→ Google。

## 4-2 活性化関数

**活性化関数**は、各ニューロンの出力に**非線形の変換**を加える関数。非線形の関数がないと、何層重ねても全体が1つの線形変換と同じになり、深くする意味がなくなる。

| 関数 | 出力の範囲 | 微分の最大値 | 主な使い道 | 弱点・特徴 |
|---|---|---|---|---|
| シグモイド | 0〜1 | **0.25** | 二値分類の**出力層** | 微分が小さく、隠れ層に使うと**勾配消失**しやすい |
| tanh | **−1〜1** | **1** | 隠れ層（かつての定番）、RNN | 0を中心に出力するのでシグモイドより学習が安定。ただし入力が大きいと微分が0に近づく |
| ReLU | 0〜∞ | 1（x>0のとき常に1） | 隠れ層の**現在の標準** | 勾配消失が起きにくく、計算が軽い。入力が負だと出力も勾配も0になり、ニューロンが学習しなくなること（**dying ReLU**）がある |
| Leaky ReLU | −∞〜∞ | 1 | 隠れ層 | 入力が負のときも小さな傾きを持たせ、dying ReLU を防ぐ |
| ソフトマックス | 0〜1（**合計が1**） | — | 多クラス分類の**出力層** | 各クラスに属する確率として解釈できる |

### なぜシグモイドは隠れ層に使われなくなったか
- シグモイドの微分は最大でも0.25。誤差逆伝播法では層ごとに微分を掛け合わせるので、10層なら最大でも 0.25¹⁰ ≒ 0.000001 となり、入力層側に誤差がほとんど伝わらない（**勾配消失**、4-5）。
- tanh は微分の最大値が1なので少しましだが、それでも入力の絶対値が大きいと微分は0に近づく。
- ReLU は正の領域で微分が常に1なので、何層掛けても勾配が小さくならない。これが ReLU が標準になった理由。

### 問われ方
- 出力の範囲を問う問題: シグモイドは0〜1、tanhは−1〜1、ソフトマックスは合計1。
- 「多クラス分類の出力層に使う関数」→ ソフトマックス。「二値分類の出力層」→ シグモイド。
- 「ReLU の欠点を改善したもの」→ Leaky ReLU（ほかにも Parametric ReLU、ELU などの改良版がある）。

## 4-3 誤差関数（損失関数）

**誤差関数**は、モデルの予測と正解のずれを1つの数値にする関数。学習とは、この値を小さくするように重みを調整すること。**タスクに応じて使い分ける**のがポイント。

| 誤差関数 | 使うタスク | 内容 |
|---|---|---|
| 平均二乗誤差（MSE） | **回帰** | 予測値と正解の差を二乗して平均したもの。大きな外れに厳しい |
| 交差エントロピー | **分類** | 正解クラスに付けた確率が低いほど大きくなる。出力層のソフトマックス（二値ならシグモイド）と組み合わせる |
| KLダイバージェンス | 分布どうしの比較 | 2つの確率分布のずれ。VAE（05章）や知識蒸留（06章）で使う |
| コントラスティブロス | 距離学習 | **2つ組**（ペア）で、同じものは近く、違うものは一定の距離（マージン）以上離す |
| トリプレットロス | 距離学習 | **3つ組**（アンカー・正例・負例）で、「アンカーと正例の距離 ＜ アンカーと負例の距離」を学ぶ。顔認識（FaceNet）で有名 |

### 交差エントロピー
- **一言で**: 正解クラスの予測確率を p とすると −log p。p が1に近いほど0に近づき、0に近いほど急激に大きくなる。
- **なぜ分類で MSE ではなくこれを使うか**: 確率の出力と相性がよく、大きく外したときに大きな勾配が出るので学習が速い。

### KLダイバージェンス
- **一言で**: 分布Pと分布Qがどれだけ違うか。同じなら0、違うほど大きい。
- **注意**: **非対称**で、PとQを入れ替えると値が変わる。そのため厳密な意味での「距離」ではない。

### コントラスティブロスとトリプレットロス（距離学習）
- **なぜ生まれたか**: 顔認証のようにクラスが膨大で、後から人が増えるタスクでは、普通の分類として学習できない。そこで「似たものを近くに配置する空間」を学ばせる。
- **違い**: コントラスティブロスはペアごとに独立して学ぶ。トリプレットロスは正例と負例の**相対的な**距離関係を同時に学ぶ。

### 問われ方
- 「回帰には MSE、分類には交差エントロピー」の対応。
- 「KLダイバージェンスの性質」→ 非対称、0以上、分布が一致すれば0。
- 「アンカー・正例・負例を使う損失」→ トリプレットロス。

## 4-4 正則化（過学習を防ぐ）

**過学習**は、訓練データには合っているが、未知のデータでは性能が出ない状態。モデルが複雑で、データが少ないほど起きやすい。**正則化**は、モデルの複雑さに罰則（ペナルティ）を課して過学習を防ぐ手法の総称。

### L0・L1・L2正則化

| | ペナルティの対象 | 効果 | 回帰に使った名前 |
|---|---|---|---|
| L0正則化 | 0でない重みの**個数** | 理想的だが計算が困難（組み合わせ最適化になる）で、ほぼ使われない | — |
| L1正則化 | 重みの**絶対値**の和 | 不要な重みを**ちょうど0**にする。**スパース**なモデルになり、特徴選択の効果がある | **ラッソ回帰** |
| L2正則化 | 重みの**二乗**の和 | 重みを全体的に**小さく**する（0にはしない）。**荷重減衰**（weight decay）とも呼ばれる | **リッジ回帰** |

- L1とL2を組み合わせたものが **Elastic Net**。
- **覚え方**: L1は「1つずつ0にして削る」（特徴選択）。L2は「2乗で全体を縮める」（滑らかにする）。
- **問われ方**: 「重みを0にして特徴選択に使える手法」→ L1／ラッソ回帰。「重みを0にはせず全体を小さくする」→ L2／リッジ回帰。

### ドロップアウト
- **一言で**: 学習時に、ニューロンをランダムに一定の割合だけ無効にする。
- **なぜ効くか**: 特定のニューロンへの依存を防ぐ。毎回違う部分ネットワークで学習するので、多数のモデルを平均する**アンサンブル学習に近い効果**が出る。
- **推論時**: すべてのニューロンを使う。学習時と出力の大きさが変わらないよう、出力を（残した割合で）補正する。
- **問われ方**: 「ドロップアウトはテスト時も使うか」→ 使わない（全ニューロンで推論する）。「どの学習手法に似た効果があるか」→ アンサンブル学習。

### 早期終了（Early Stopping）
- **一言で**: 検証データの誤差が**下がらなくなった（上がり始めた）時点**で学習を止める。
- **なぜ**: 訓練データの誤差は下がり続けても、検証データの誤差はある時点から上がる。そこが過学習の始まり。
- **小ネタ**: 手軽で効果が高いことから、ヒントンは「Beautiful FREE LUNCH」と呼んだ。4-6 の「ノーフリーランチ定理」との対比で出題されることがある。

## 4-5 誤差逆伝播法

### 誤差逆伝播法（バックプロパゲーション）
- **一言で**: 出力の誤差を**出力層から入力層へ逆向きに**伝え、各重みの勾配（その重みを少し動かすと誤差がどれだけ変わるか）を効率よく求める方法。
- **なぜ必要か**: 重みは何万〜何十億個もあり、1つずつ動かして誤差の変化を測るのは現実的でない。逆伝播なら、1回の逆向きの計算ですべての勾配が求まる。
- **仕組み**: 合成関数の微分の公式である**連鎖律**（∂L/∂w = ∂L/∂y × ∂y/∂w のように、微分を掛け算でつなぐ）を使う。

### 信用割当問題
- **一言で**: 出力の誤差に対して、どの重みに**どれだけ責任があるか**をどう決めるか、という問題。
- **関係**: 誤差逆伝播法は、各重みの勾配を求めることでこの問題に答えを出した。

### 勾配消失問題と勾配爆発問題

| | 何が起きるか | 主な原因 | 主な対策 |
|---|---|---|---|
| **勾配消失問題** | 入力層側に近づくほど勾配が0に近づき、重みが更新されない | 微分が1より小さい活性化関数（シグモイド等）を深く重ねる | **ReLU**、適切な重みの初期値（**Xavier**はシグモイド・tanh向け、**He**はReLU向け）、**バッチ正規化**、**スキップ結合**（ResNet）、事前学習、RNNでは **LSTM** |
| **勾配爆発問題** | 勾配が急激に大きくなり、重みが発散する | 1より大きい値を何度も掛ける。系列が長い**RNN**で起きやすい | **勾配クリッピング**（勾配の大きさに上限を設ける）、適切な初期値 |

- **問われ方**: 「勾配消失の対策として**不適切な**ものはどれか」という形がよく出る。シグモイドへの変更や、層をさらに深くすることなどが誤りの選択肢になる。
- 対策のうちバッチ正規化・スキップ結合・LSTM の中身は05章で扱う。

## 4-6 最適化手法

### 勾配降下法と学習率
- **勾配降下法**: 誤差関数の勾配（傾き）を求め、**坂を下る方向**へ重みを少しずつ動かして誤差の最小点を探す。
  - 更新式のイメージ: 新しい重み ＝ 今の重み − 学習率 × 勾配
- **学習率**: 1回に動かす幅。**大きすぎる**と最小点を飛び越えて発散し、**小さすぎる**と学習が遅く、局所最適解で止まりやすい。

### 局所最適解・大域最適解・鞍点

| | 内容 |
|---|---|
| 大域最適解 | 誤差関数全体で最も小さい点。本当に目指したい解 |
| 局所最適解 | 近くでは最小だが、全体では最小ではない点（小さなくぼみ） |
| 鞍点 | ある方向から見ると最小、別の方向から見ると最大になる点（馬の鞍の形）。勾配が0なので更新が止まる。高次元では局所最適解より鞍点の方がずっと多い |
| プラトー | 鞍点の周りなどで勾配がほぼ0の平らな領域が続き、学習が停滞する状態 |

### バッチ学習・ミニバッチ学習・オンライン学習

| | 1回の更新に使うデータ | 長所 | 短所 |
|---|---|---|---|
| バッチ学習 | **全データ** | 更新が安定する | 計算・メモリの負荷が大きい。局所最適解から抜けにくい |
| ミニバッチ学習 | **数十〜数百件**のまとまり | 安定性と効率のバランスがよい。**現在の標準** | バッチサイズの調整が必要 |
| オンライン学習 | **1件ずつ** | 新しいデータを逐次取り込める | 外れ値の影響を受けやすく、不安定 |

- **確率的勾配降下法（SGD）**: ランダムに選んだデータ（1件、または実務ではミニバッチ）で勾配を求めて更新する方法。更新のゆらぎ（ノイズ）がかえって局所最適解や鞍点から抜け出す助けになる。

### エポックとイテレーション（計算問題が出る）
- **エポック**: 訓練データ全体を**1周**すること。
- **イテレーション**: 重みを**1回更新**すること（ミニバッチ1つ分）。
- **計算例**: 訓練データ10,000件、バッチサイズ100なら、1エポックは 10,000 ÷ 100 ＝ **100イテレーション**。これを10エポック行うと、重みの更新は **1,000回**。

### 最適化手法の系譜

勾配降下法の弱点（遅い、鞍点で止まる、パラメータごとに適した学習率が違う）を改良する流れで整理する。

```
勾配降下法 / SGD
 ├─ 「勢い」を付ける ──────── モーメンタム
 │
 └─ 学習率を自動で調整 ───── AdaGrad
                               │ 弱点: 学習率が0に近づき、学習が止まる
                               ├─ RMSProp（直近の勾配を重視する指数移動平均で解決）
                               └─ AdaDelta（同じく解決。学習率の初期設定も不要）

モーメンタム ＋ RMSProp ──→ Adam（現在の定番）
                              │ 弱点: 最終的な汎化性能でSGDに劣ることがある
                              ├─ AdaBound（Adamの学習率に上限・下限を設け、学習が進むと徐々にSGDに近づける）
                              └─ AMSBound（Adamの改良版 AMSGrad に同じ上限・下限を設けたもの）
```

| 手法 | 一言で | ポイント |
|---|---|---|
| モーメンタム | 過去の更新方向に**慣性**を付ける | 坂を転がるボールのように、鞍点や平らな所でも勢いで進める。振動が減る |
| AdaGrad | パラメータごとに学習率を調整する | よく更新されるパラメータは学習率を小さく、まれなものは大きくする。過去の勾配の二乗を**全部足す**ので、学習率がどんどん小さくなる |
| RMSProp | AdaGradの改良 | 勾配の二乗を**指数移動平均**にして古い情報を忘れさせ、学習率が0になるのを防ぐ |
| AdaDelta | AdaGradの改良 | RMSPropと同じ問題を解決し、学習率の初期値の設定も不要にした |
| Adam | **モーメンタム＋RMSProp** | 勾配の平均（1次モーメント）と二乗の平均（2次モーメント）の両方を使う。速く安定するので広く使われる |
| AdaBound / AMSBound | Adamの改良 | 学習率に上限・下限を設け、「序盤はAdamのように速く、終盤はSGDのように安定して」収束させる |

- **問われ方**: 「Adamはどの2つを組み合わせたものか」→ モーメンタムとRMSProp。「AdaGradの問題点」→ 学習率が0に近づき、学習が進まなくなる。

### ハイパーパラメータとその探索
- **ハイパーパラメータ**: 学習前に**人が決める**値。学習率、バッチサイズ、エポック数、層の数、ユニット数、ドロップアウト率、正則化の強さなど。
- **グリッドサーチ**: 候補を格子状に並べ、**すべての組み合わせ**を試す。確実だが、パラメータが増えると組み合わせが爆発的に増える。
- **ランダムサーチ**: 範囲内から**ランダムに**選んで試す。性能に効くパラメータが一部だけのときは、同じ試行回数でもグリッドサーチより効率よく良い値を見つけやすい。
- （補足）過去の試行結果から次に試す値を賢く選ぶ**ベイズ最適化**もある。

### 二重降下現象（Double Descent）
- **一言で**: モデルを大きく（またはデータ量やエポック数を増や）していくと、テスト誤差が「下がる → 上がる（過学習）→ **再び下がる**」現象。
- **なぜ注目されたか**: 従来の統計学は「モデルが複雑すぎると過学習で悪くなる」と考えていた。しかし、ある大きさを超えると再び良くなるため、巨大モデルの成功を説明する手がかりとして注目された。

### ノーフリーランチ定理
- **一言で**: **あらゆる問題で最良になる万能なアルゴリズムは存在しない**、という定理。
- **意味**: 問題ごとに適した手法を選ぶ必要がある。
- **問われ方**: 早期終了の「Beautiful FREE LUNCH」と混同させる選択肢に注意。

## 章末まとめ（暗記必須）

**人物・年号**
- 1958 単純パーセプトロン（ローゼンブラット）／1969 XORを解けないと指摘（ミンスキー、パパート）
- 1986 誤差逆伝播法（ラメルハートら）／2006 事前学習でディープラーニングの始まり（ヒントン）／2012 AlexNet

**数値**
- シグモイドの微分の最大値は **0.25**、tanh は **1**
- 出力の範囲: シグモイド **0〜1**、tanh **−1〜1**、ソフトマックスは**合計1**
- 1エポックのイテレーション数 ＝ データ数 ÷ バッチサイズ

**対応関係**
- 回帰 → MSE／分類 → 交差エントロピー
- 多クラス分類の出力層 → ソフトマックス／二値分類の出力層 → シグモイド／隠れ層 → ReLU
- L1 → 重みが0、スパース、ラッソ回帰／L2 → 重みが小さくなる、荷重減衰、リッジ回帰
- 初期値: Xavier → シグモイド・tanh／He → ReLU
- Adam ＝ モーメンタム ＋ RMSProp
- 勾配消失の対策 → ReLU、重みの初期値、バッチ正規化、スキップ結合、LSTM、事前学習／勾配爆発の対策 → 勾配クリッピング

**ひっかけ注意**
- ドロップアウトは推論時には使わない。
- KLダイバージェンスは非対称なので、厳密な意味での距離ではない。
- 「ノーフリーランチ定理」（万能な手法はない）と「Beautiful FREE LUNCH」（早期終了）は別物。
- 鞍点は勾配が0だが、最小点ではない。
