# 00 全体マップ

> テキスト全10章を1ページで見渡すための章。最初にこれを読み、試験直前にも見返す。

## この章で押さえること

- G検定の範囲は **「AIの歴史（01・02）→ 機械学習（03）→ ディープラーニングの仕組み（04・05）→ 応用（06）→ 社会実装（07）」** の流れと、それを支える **数学（08）**、守るべき **法律（09）・倫理（10）** でできている。
- 出題が多い**重点分野は 04・05・06（ディープラーニング）と 09・10（法律・倫理）**。学習時間はここに多く割く。
- 各章は通読用（「この章で押さえること」「全体像」「章末まとめ」）と復習用（各節の詳しい解説）に分かれている。Step 1 では通読用の部分だけを読む。

## 章をまたぐテーマ

試験では、1つのテーマが複数の章にまたがって問われる。次の組み合わせは、該当する節を続けて読むと理解が深まる。

| テーマ | 流れ | 読む節 |
|---|---|---|
| 勾配消失との戦い | シグモイドの限界 → ReLU・初期値 → バッチ正規化・ResNet → LSTM | 04-2、04-5 → 05-4、05-5、05-6 |
| 系列データの系譜 | RNN → LSTM → Attention → Transformer → BERT/GPT → LLM | 05-6、05-7 → 06-2、06-8 |
| 画像認識の歴史 | ネオコグニトロン → LeNet → AlexNet（第3次ブーム）→ ResNet → ViT | 02-4 → 05-1 → 06-1 |
| データの偏り | サンプリングバイアス → 公平性の問題 → ガイドライン上の対策 | 03-6 → 07-2 → 10-4 |
| 評価と過学習 | 過学習の見分け方 → 正則化・早期終了 → データ拡張 | 03-6 → 04-4 → 05-9 |
| 生成AIとルール | LLMの仕組み → 著作権・個人情報 → ハルシネーション・プロンプトインジェクション | 06-8 → 09-1、09-2 → 10-6、10-7 |
| 確率とベイズ | ベイズの定理 → ナイーブベイズ → 交差エントロピー・KLダイバージェンス | 08-3、08-6 → 03-2 → 04-3 |

## 読み方（学習ロードマップとの対応）

| Step | テキストの使い方 |
|---|---|
| **Step 1 全体像をつかむ** | 各章の「この章で押さえること」「全体像」「章末まとめ」だけを読む。1章10分程度で、全章を2時間弱で一周できる。 |
| **Step 2 問題集を解く** | テキストは開かずに解く。間違えた問題の用語を控えておく。 |
| **Step 3 苦手分野を復習する** | 得点率が70%未満の章だけ、該当する節の詳しい解説を読む。「なぜ生まれたか」「問われ方」を中心に読む。 |
| **Step 4 解き直す** | 解き直して70%を超えない章は、もう一度 Step 3 に戻る。 |

- 全文を読む場合の目安は、04章が約30分、06章が約1.5時間で、全章で約8〜9時間。Step 1 で全文を読もうとしないこと。
- 試験直前は、全章の「章末まとめ（暗記必須）」と、このページの「各章の要点」を見返す。

## 章末まとめ（暗記必須）

**計算問題が出る箇所**
- 混同行列 → 正解率・適合率・再現率・F値（03-6）
- エポックとイテレーションの回数（04-6）
- 畳み込みの出力サイズ ＝ (入力 ＋ 2×パディング − フィルタ) ÷ ストライド ＋ 1（05-1）
- 平均・分散・標準偏差、ベイズの定理（08-1、08-3）
- ハノイの塔の最小手数 2ⁿ−1（02-1）

**最新動向（2026-10-23時点。試験に出るのは公式シラバスの範囲）**
- シラバスは G2024#6 以降の版で、最新は第1.4版（2026-05-11）。ChatGPT と GPT-n はキーワードから外れ、「破壊的忘却」は「破滅的忘却」に表記が変わった（06章）。
- EU AI法のハイリスクAIへの義務は、2026年7月の改正で適用が延期された（10章）。
- 個人情報保護法の改正が2026年7月に成立したが、施行は公布から2年以内（09章）。
- 直近の改正は、試験問題にまだ反映されていない可能性がある。「いつ・何が決まったか」を区別して、改正前と改正後の両方を押さえる。

## 用語集との関係

- 用語集（`G検定用語集_初学者向け.md`）の全見出しは、いずれかの章の本文で扱っている（2026-10-23 確認）。そのため `未収録用語.md` は作成していない。
- 各章の末尾に、次の2つを記録している。
  - **用語集追加候補**: 本文で扱ったが、用語集に見出しがない用語
  - **用語集の記述との相違点**: 用語集の説明の誤りや古い記述
- 用語集の説明とテキストの説明が食い違うときは、**テキストの説明を正とする**（Webや公式資料で確認済みの内容）。特に次の項目は試験に影響しやすい。
